# Validated calibrated reference outputs

These compact cohort-level tables are copied from the validated full runs and are provided for regression comparison and manuscript traceability.

- `gm45/`: sweep, interpolation, best-fit, and model-versus-experiment tables
- `gm5/`: calibrated passive-atlas metrics, quality control, and statistics
- `gm6/`: calibrated synaptic cell metrics, age summaries, and failure table
- `gm7/`: one-factor sensitivity results, summaries, and failure table

These files are reference results, not substitutes for the authorised reconstruction inputs. Regenerated analyses should be written under `results/` and compared with these tables rather than overwriting them.
