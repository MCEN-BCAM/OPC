# Licensing decision required

No licence has been applied to this draft repository. Without an explicit licence, others may view the public code but do not automatically receive permission to reuse, modify, or redistribute it.

Before publication, the authors and institutional technology-transfer contacts should select one licence. Plausible options include:

- **BSD 3-Clause**: permissive and familiar in scientific Python projects;
- **Apache-2.0**: permissive with an explicit patent grant;
- **CeCILL-B**: a permissive French-law licence often considered by French public research institutions;
- **GPL-3.0** or **CeCILL**: copyleft alternatives requiring derivatives to preserve reciprocal terms.

The choice should account for Inria/institutional policy, ownership of contributed code, and compatibility with all dependencies. Once agreed, replace this file with the canonical licence text and update `pyproject.toml`, `CITATION.cff`, and the README.
